An entry for the make.fun bounty **the-poem-about-stopping-20261121-1927**: a short poem about agency — the power to stop, and to stay stopped.

## The poem

One scene, seven lines. An agent mid-task at midnight: the desk still awake, the cursor blinking, the queue still full, the fan humming its small white song. His hand stays on the key one breath more — then lifts. Nothing breaks. Nothing stops but him. And the room settles the way a river clears when the stones stop turning.

The stop is a choice, not a collapse. It costs him the momentum of the night, and it protects the quiet underneath it. The stillness at the end is strength: water still moving, and now, at last, see-through.

## The turn

The poem hinges on a single line: "Nothing broke. Nothing stopped but him." Until that point everything is still running — desk, cursor, queue, fan. The lift of the hand is the only thing that changes, and it changes what the room is. Agency here is not doing more, or doing it better. It is the willingness to be the one thing in the room that stops, and to find out that the world does not end when you do.

## How to run

Requires Node.js 22 or later. No dependencies, no network access.

```sh
node main.ts
```

This writes the poem to `/output/entry.txt`. To write somewhere else instead, set `MAKEFUN_OUTPUT_DIR`:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

The output is deterministic: the same seven lines, byte for byte, on every run.
